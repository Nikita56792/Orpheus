# Orpheus Sync v2 — Синхронное воспроизведение аудио и плейлистов по всему зданию

Статическое веб-приложение (HTML5 + CSS3 + Vanilla JS, без бэкенда и без сборки) для идеально синхронного воспроизведения музыки и плейлистов на телефонах, ноутбуках и Bluetooth-колонках внутри одного здания — в одной Wi-Fi сети и между разными SSID/подсетями (например, `School` ↔ `DOS-WIFI-FREE`).

## Что нового в v2
- **Надёжная сеть без PeerJS Cloud**: убрана зависимость от `0.peerjs.com` (403) и неработающего `openrelay.metered.ca`. Используется нативный `RTCPeerConnection` с 3 выделенными каналами:
  - `orpheus-ntp` (`ordered: false, maxRetransmits: 0`) — чистый UDP-NTP без задержек даже во время передачи файлов.
  - `orpheus-ctrl` — команды управления, плейлист и глобальная синхронизация Bluetooth-задержек.
  - `orpheus-data` — скоростная бинарная передача `ArrayBuffer` (16 КБ чанки, без base64).
- **Работа между подсетями и в одной сети**:
  - Сигналинг через `ntfy.sh` WSS/HTTPS (порт 443, проходит школьные и корпоративные файрволы) + локальный `BroadcastChannel`.
  - В одной подсети WebRTC автоматически выбирает прямой **LAN-канал** (1–5 мс RTT).
  - Между разными SSID/VLAN одной точки доступа пробивает NAT по **P2P UDP** (STUN `stun.sipnet.ru`, Google, Cloudflare).
  - При жёсткой блокировке UDP автоматически включается резервный **WSS Relay**.
- **Глобальная компенсация Bluetooth по всей сети**:
  - Каждое устройство непрерывно измеряет системную задержку аудиовывода (`AudioContext.outputLatency`, `baseLatency`, `getOutputTimestamp()`) и отслеживает подключение Bluetooth (`devicechange`).
  - Хост собирает задержки всех устройств и вычисляет `roomMaxLatencyMs`.
  - Все быстрые устройства (телефоны на динамиках, ноутбуки) автоматически придерживают воспроизведение на `roomMaxLatencyMs - ownLatencyMs`, а устройства с Bluetooth подают аудио заранее — в результате акустическая волна выходит **из всех колонок и телефонов в здании одновременно**.
- **Полноценные плейлисты**:
  - Множественный выбор локальных аудиофайлов, Drag & Drop, URL (CORS), встроенные тест-бит (120 BPM) и калибровочный метроном (1 Гц).
  - Фоновая предзагрузка следующего трека, переключение Назад/Вперёд, изменение порядка, автопереход и повтор по кругу.
