# Orpheus Sync — Синхронное воспроизведение музыки на нескольких устройствах

Статическое веб-приложение (HTML5 + CSS3 + Vanilla JS, без бэкенда и без сборки) для синхронного проигрывания музыки на телефонах и ноутбуках. Готово к бесплатному деплою на **GitHub Pages**.

## Ключевые технологии и решения
- **Сеть и передача аудио**: **PeerJS (WebRTC DataChannel)** — прямое P2P-соединение без API-ключей и квот баз данных. Локальный аудиофайл Хоста нарезается на чанки по 16 КБ с контролем буфера (`bufferedAmount`) и передаётся Слушателям. Также поддерживаются прямые CORS-ссылки и встроенный тест-бит (120 BPM).
- **Синхронизация часов (NTP)**: 4-меточный алгоритм (`t0, t1, t2, t3`) поверх монотонного таймера `performance.now()` с фильтрацией по минимальному RTT и сглаживанием EMA.
- **Точный старт (Scheduled Playback)**: `Web Audio API` (`AudioContext.currentTime`) с буфером запуска `+2.8 с` и обратным отсчётом.
- **Обход Autoplay на iOS/Android**: единая кнопка «Подключиться и разблокировать звук» прогревает `AudioContext`, 1-сэмпловый буфер и тихий WAV-поток.
- **Компенсация дрейфа и Bluetooth**: автокоррекция скорости `playbackRate` (±1.5%, незаметна на слух) при дрейфе `12–160 мс`, жёсткий ресинк с микро-фейдом при `>160 мс`, и кнопки ручной подстройки `-50 / -10 / +10 / +50 мс`.
- **Защита от сна**: `Screen Wake Lock API` с авто-восстановлением при возврате на вкладку.

## Быстрый деплой на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub (например, `orpheus-sync`).
2. Загрузите все файлы проекта (`index.html`, `styles.css`, папку `js/`) в ветку `main`.
3. Перейдите в **Settings → Pages → Build and deployment**.
4. Выберите **Source: Deploy from a branch**, ветку **`main`** и папку **`/ (root)`**, нажмите **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/` (HTTPS включён автоматически — это обязательно для WebRTC и Wake Lock API).

## Локальный запуск для тестирования
```bash
python3 -m http.server 8080
```
Откройте `http://localhost:8080` в двух вкладках (в одной создайте комнату как Хост, во второй подключитесь по коду или ссылке).
