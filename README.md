# Orpheus Sync — Синхронное воспроизведение аудио и плейлистов по всему зданию

Статическое веб-приложение (HTML5 + CSS3 + Vanilla JS, без бэкенда и без сборки) для идеально синхронного воспроизведения музыки и плейлистов на телефонах, ноутбуках и Bluetooth-колонках внутри одного здания — в одной Wi-Fi сети и между разными SSID/подсетями (например, `School` ↔ `DOS-WIFI-FREE`).

Рабочая версия на GitHub Pages: **https://nikita56792.github.io/Orpheus/**

## Ключевые возможности
- **Прогрессивный стриминг во время кэширования**: большие аудиофайлы начинают играть сразу после получения компактного стартового сегмента (< 1 сек), пока полный оригинал докачивается в фоне и бесшовно подменяет поток без пауз и щелчков.
- **Мгновенный Late Join**: устройства, подключившиеся уже во время воспроизведения, автоматически получают потоковый сегмент с текущей позиции, калибруют часы за ~200 мс и встраиваются в единый звук.
- **Полностью автоматическая компенсация Bluetooth по всей сети**: каждое устройство непрерывно измеряет системную задержку (`AudioContext.outputLatency`, `baseLatency`, `getOutputTimestamp()`, `devicechange`), Хост вычисляет максимум по зданию, и все быстрые устройства автоматически выравниваются под самые медленные Bluetooth-колонки.
- **Надёжная сеть и высокая скорость**: нативный `RTCPeerConnection` с 3 каналами (`orpheus-ntp` UDP без блокировок, `orpheus-ctrl`, `orpheus-data` с динамическими бинарными чанками до 60 КБ и 1 МБ окном) + автоматический резервный `WSS Relay`.
- **Плейлисты и живые проценты загрузки**: множественный выбор файлов, Drag & Drop, URL (CORS), встроенные тест-бит 120 BPM и метроном 1 Гц, фоновая предзагрузка следующего трека и реальные проценты загрузки по каждому устройству на экране Хоста.
- **Минималистичный дизайн в стиле Apple**: автоматическое переключение светлой (`#F5F5F7`) и тёмной (`#000000`) темы по системным настройкам (`prefers-color-scheme`).
